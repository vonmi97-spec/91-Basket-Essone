# 91 : Basket Essonne

Appli Android (non officielle) : matchs du week-end du championnat départemental de l'Essonne, toutes catégories (U7 → Seniors), avec logos des clubs et gymnases, issus de l'API publique de la FFBB.

## Fonctions
- Week-end en cours, précédent, suivant (vendredi → dimanche)
- Filtres catégorie (U9, U11, U13…, Seniors) et féminin / masculin
- Recherche d'une équipe, d'un club ou d'un gymnase
- Vues Matchs, Gymnases, Clubs (toucher un club = ses matchs)
- Favoris ★, scores des matchs joués, bouton Itinéraire vers le gymnase

## Obtenir l'APK
1. Crée un dépôt GitHub et mets-y tous ces fichiers (en gardant les dossiers).
2. L'onglet **Actions** lance « Construire l'APK » (~5 min).
3. Télécharge `Basket91-Essonne.apk` dans l'onglet **Releases**, puis installe-le
   (autoriser « sources inconnues » si Android le demande).

## Si aucun match n'apparaît
⚙️ Réglages → saisir le nom exact du comité organisateur tel qu'il apparaît sur ffbb.com.
